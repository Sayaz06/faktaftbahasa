# Istigfar Kindle

Versi ringan Istigfar + Ilmu untuk browser Kindle e-reader.

## Skrin disasarkan
- Tinggi: 15.78 cm
- Lebar: 10.86 cm
- Model: Kindle basic (2022/2024) 6" 300ppi

## Ciri
- Countdown Laci Bahasa
- Countdown Laci Fakta
- Next laci + Masuk SR
- Sync real-time dengan app phone (Firestore)
- Tiada senarai SR, tiada edit, tiada video

## Live
Aktifkan GitHub Pages (Settings → Pages → Deploy from branch `main` / root).

URL contoh: `https://sayaz06.github.io/resit/`

## Phone app
Mesti write ke `users/{uid}/kindle_session/current` dan listen `kindle_session/command`.
