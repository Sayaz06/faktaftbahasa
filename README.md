# Istigfar Kindle

Versi ringan Istigfar + Ilmu untuk browser Kindle e-reader.

## Flow
- Laci Bahasa → [SR overdue?] → FG (hafal gambar x5) → F0 → F1 → F2 → Daftar SR → Next perkataan
- Laci Fakta → [SR overdue?] → Per baris: FG (hafal gambar x5) → F1x5 → (JQ Motivasi) → F2x5 → Daftar SR baris

## Fasa Gambar (FG)
Gambar kekal di tempat yang sama. Ayat di bawah:
Hafal gambar ini terlebih dahulu. Tutup mata dan bayangkan imej tersebut. Buka mata semula, kemudian tekan SETERUSNYA. Ulang 5 kali.

Flip dilarang pada FG (popup).
FG diskip jika laci/baris tiada imageUrl.
